## How to find a skill (step by step)

1. Open a topic file above, or open `all-skills.csv` in Excel or Google Sheets.
2. Press **Ctrl+F** and search for a word, for example `instagram`, `ghidra` or `music`.
3. Click the skill name. It opens the skill folder on GitHub.
4. Install it in one of these ways:
   - `npx skills add <owner>/<repo> --skill <skill-name>`
   - or copy the folder into `.claude/skills/` (this project) or `~/.claude/skills/` (all projects)

Quick search in the terminal:
```bash
grep -i "instagram" skills-index/all-skills.csv
```

## ⚠️ Safety

- These are community skills. Read a skill's `SKILL.md` before you install it.
- Don't install thousands of skills at once. Every installed skill adds its description to Claude's context, so Claude gets slower and makes worse choices. Install only the ones you need.
- Star counts and install numbers are a snapshot and change every day.
